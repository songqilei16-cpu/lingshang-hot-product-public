# 领商 · 爆品生成（Web 前端与联调工程）

本仓库为「领商」商家工作台 **商品 > 爆品运营 > 爆品生成** 页面的高保真前端实现，已按设计稿规范还原视觉、交互与 5 个前后端/AI Agent 标准接口。

## 项目结构

```text
├── index.html          # 主入口页面（支持本地双击预览或 GitHub Pages 直接部署）
├── styles.css          # 1440×1024 1x 视觉规范、吸底底栏、收起态侧栏与弹窗吸顶表头
├── api.js              # 后端 & AI Agent 统一接口适配层（内置 USE_MOCK 开关）
├── app.js              # 页面交互逻辑与表单/弹窗状态管理
├── API_SPEC.md         # 后端与 AI Agent 联调接口文档（5 个标准接口）
└── assets/             # 设计稿原始图标、领商 Logo 与静态样机图
```

## 快速预览

- **本地预览**：直接用浏览器打开根目录下的 `index.html`（默认开启 `USE_MOCK: true`，无需后端即可体验完整流程）。
- **线上预览（GitHub Pages）**：在仓库 `Settings → Pages` 选择 `main` 分支 `/ (root)` 目录保存即可生成公网预览链接。

## 核心交互流程

1. **关联商品**：点击「+ 选择商品」打开 200 条商品选择器（表头吸顶固定），最多可选 100 件（满 100 件其余置灰不可点），表头复选框支持全选 / 部分选中（半选）/ 取消全选三态，确认后回显至主表并默认按 `3 条/页` 分页。
2. **爆款链接识别**：未关联商品点击「识别」提示「请先关联商品」；已关联商品未填链接提示「请输入爆款链接」；两者均满足后调用 Agent 识别接口生成「标题预览」并展示「重新生成」提示条。
3. **标题校验与下载**：支持手动编辑标题或点击「重新生成」；点击「校验并下载」时依次校验必填项、内容安全敏感词（涉黄/暴力犯罪/涉毒/涉赌/涉政）及平台广告规则，通过后自动导出 CSV 方案。

## 后端 & Agent 联调入口

请直接查阅 [API_SPEC.md](./API_SPEC.md)，修改 `api.js` 顶部的 `BACKEND_BASE_URL`、`AGENT_BASE_URL` 并将 `USE_MOCK` 改为 `false` 即可切换真实联调。
